# InfinityArtWorld

Welcome to the InfinityArtWorld project! This project is an online platform for purchasing handmade art products. Below you will find information about the project structure, setup instructions, features, and usage guidelines.

## Project Structure

```
infinityartworld
├── css
│   └── style.css          # Styles for the website
├── js
│   └── app.js            # JavaScript functionality for user interactions
├── data
│   └── products.json     # Product data in JSON format
├── assets
│   ├── images
│   │   └── .gitkeep      # Directory to store images
│   └── icons
│       └── .gitkeep      # Directory to store icons
├── index.html            # Main landing page
├── shop.html             # Page to browse products
├── product.html          # Detailed product information
├── cart.html             # Shopping cart page
├── checkout.html         # Checkout page for completing purchases
├── package.json          # npm configuration file
└── README.md             # Project documentation
```

## Setup Instructions

1. **Clone the Repository**: 
   ```bash
   git clone <repository-url>
   cd infinityartworld
   ```

2. **Install Dependencies**: 
   Make sure you have Node.js installed. Then run:
   ```bash
   npm install
   ```

3. **Run the Project**: 
   You can open the `index.html` file in your web browser to view the project.

## Features

- Browse a variety of handmade art products.
- Detailed product pages with descriptions, images, and pricing.
- Add products to the shopping cart and manage quantities.
- Checkout process for completing purchases.

## Usage Guidelines

- Navigate through the website using the provided links in the header.
- Use the shopping cart to review selected items before proceeding to checkout.
- Ensure to fill in all required fields during the checkout process for a successful transaction.

Thank you for checking out InfinityArtWorld! We hope you enjoy exploring our handmade creations.
